## 下午：B1 故障排除 10 分闭环（A/B 半车啮合提前兑现）

- **故障 1 OSD down（5 分）**：`ceph orch daemon stop osd.1` 注入 → `ceph health detail` 直接点名 `osd.1 (host=master2) is down` + 27 个 PG `active+undersized+degraded`（副本缩编）→ `orch daemon start` 30 秒回 HEALTH_OK
- **故障 2 MON down（5 分）**：`orch daemon stop mon.master2` 注入 → `HEALTH_WARN 1/3 mons down, quorum master1,master3` → orch start 回 quorum 三台齐

systemd 单元名三大坑（全部实战踩过，已写进命令卡）：
1. `<fsid>` 占位符被当真敲 → bash 重定向报错 → 见尖括号就替换
2. `@` 被控制台吞 → `could not be found` → 先查回显
3. 解法：**`systemctl start ceph-*mon*` 用通配符让 bash 展开完整单元名**，零特殊符号

🔑 核心认知：**orch 靠集群活，systemctl 靠机器活**——quorum 掉到只剩 1 个时 orch 发不出去，systemctl 是唯一保命路。
