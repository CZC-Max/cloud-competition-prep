## 已沉淀的经验

1. **plan = 预演，apply / destroy = 真执行**（第 2 轮卡壳点）
   `plan -destroy` 只做推演、什么都不删，输出里 `-> null` 是"如果销毁会怎样"的预览。
   完整顺序必须是：**预演(plan -destroy) → 真删(destroy) → 验空(state list) → 控制台复核**。
2. **Terraform 幂等**（第 1 轮发现）：资源已存在且与配置一致时，重复 `apply` → `No changes`，
   不会重复建。考场不确定建没建过，重跑一遍 apply 即可确认。
3. **公网 IP 会复用**：三轮都是 `8.149.236.11`（同地域同可用区，释放的 IP 回池再分配）。
   → **IP 不是资产，资源销毁即归零**，识别资源靠实例 ID（`i-bp1...`），不靠 IP。
