# scripts/

放可复用的运维 / 安全脚本。**每个脚本都要有中文注释头**（用途、用法、适用环境）。

## 规划

| 目录 | 用途 | 状态 |
|---|---|---|
| `hardening/` | Jam 模块：系统加固一键检查（SSH、服务最小化、文件权限、SUID 排查） | ⬜ 待写 |
| `fault-inject/` | 故障复现脚本，配合 10 张故障卡自埋自排 | ⬜ 待写 |
| `inspect/` | 云上资产盘点 / 安全基线巡检（Python） | ⬜ 待写 |

## 约定

1. 脚本头部必须写明：用途、用法示例、适用系统、日期
2. 涉及 SSH / 权限变更的脚本，**默认只检查不改**（dry-run），要实际修改需显式加 `--apply`
3. 所有脚本仅用于**自有或明确授权**的环境
